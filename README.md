# Exhume APFS

The Exhume APFS documentation is maintained at [forensicxlab.com](https://www.forensicxlab.com/docs/exhume_apfs/getting-started).

Disk-image commands accept `--password-file PATH` or `--password-stdin` for
encrypted image containers supported by `exhume_body`. With no explicit source,
a terminal prompts without echoing the password. Image-container credentials are
separate from encryption within an APFS container.
